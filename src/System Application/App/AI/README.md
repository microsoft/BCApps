# AI SDK

The **Troubleshooting Sessions** list and card show saved troubleshooting reports from the platform's read-only virtual table. The list shows the newest reports first. The card displays the owner name when the viewer can read it and shows the saved report as JSON.

The list defaults to active cases. **Show All Cases** includes closed cases without expanding report access. Users cannot edit reports, delete them, or reopen cases. **Close Case** is available only to the owner of an active case and changes only the case state. Troubleshooting status describes the AI iteration, not whether the case is closed.
