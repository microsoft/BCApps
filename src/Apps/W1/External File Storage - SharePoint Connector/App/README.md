# External File Storage - SharePoint Connector
This connector allows access to Share Point Files and Folder.
A proper App Registration with SharePoint API permissions is needed. This release uses the SharePoint REST API, not Microsoft Graph. Grant the permission matching the authentication type: the application permission Sites.FullControl.All for Certificate (client-credentials, app-only) authentication, or the delegated permission AllSites.Manage for Client Secret (authorization-code) authentication.

File and folder operations use SharePoint ResourcePath endpoints so legal names containing `#` or `%` are addressed unambiguously. Existing URL-based SharePoint Client APIs remain unchanged; the connector uses separate decoded-path APIs.

**REST Base Folder Path Format** defaults to **URL**, including existing accounts. Percent-encoded base folders such as `/sites/ProjectX/Shared%20Documents` are decoded once before the ResourcePath request is constructed. Choose **Decoded Path** when a folder name literally contains a percent sequence, for example `Reports%20Archive`. Raw spaces, `#`, and non-encoded percent characters can also be used in decoded paths. The site prefix is decoded from the SharePoint site URL, but paths and filenames supplied to file operations are never unescaped.
