# Apply Customer Communication Standards

Format outgoing customer messages, including clarification replies, sales quote confirmations, and sales order confirmations. Apply formal tone, recipient language, simple HTML, and readable document-line tables, including to drafts already written in HTML.

Use a formal tone, simple HTML, and the recipient's required language.

Preserve all facts, line details, disclosures, questions, and required table rows/columns. Do not replace them with totals, samples, or a reference to the PDF. Use HTML rather than Markdown.

Keep tables clean and readable, with spacing, padding, sufficient column widths, and all columns left-aligned, including numbers.

Return the HTML and identify any formatting requirement that could not be fulfilled, without inventing facts or claiming the message is ready to send. Formatting itself does not send messages, create documents, or change attachments.
