# Convert Quote to Sales Order

Convert an existing sales quote into a sales order, verify the result, and return the resulting order identifier and any unresolved document issues.

Keep the quote and resulting order identifiers with completed progress. Resume the existing order after conversion; check current BC state before repeating an uncertain action.

## 1. Convert

Open the identified quote and use "Make Order". If asked to create a customer, select "Yes" and proceed. Confirm conversion, retain the resulting sales order number, and open it. Do not repeat conversion or customer creation when the order already exists.

## 2. Handle order issues

Inspect the resulting order for unresolved document errors and request assistance for actual blockers. After an issue is resolved, reread the order to capture its current lines and dates.

## 3. Return the result

Return the quote identifier, resulting sales order number, actual conversion state, and any unresolved document issue. Do not claim conversion before the actual result confirms it. Do not prepare a confirmation PDF or send customer messages here.
