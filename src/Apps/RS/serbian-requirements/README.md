# Serbian E-Invoicing Requirements

## Experiment scope

Prototype support for Serbian electronic invoicing.

Current scope:

- Outgoing documents only
- Sales Invoice only
- Generation of the Serbian electronic invoice format

API submission to SEF is outside the initial prototype scope.

## Sources

- `official-specification.pdf`
  Original official documentation. Treat this as the authoritative source.

- `specification.md`
  Markdown representation of the relevant official specification for repository analysis.
  If information conflicts with the PDF, the PDF takes precedence.

- `samples/Faktura.xml`
  Example Serbian electronic Sales Invoice.
  Treat it as a sample, not as the sole source of normative requirements.

## Important

Do not infer regulatory requirements that are not supported by the provided specification.
Report unclear or missing requirements as assumptions or open questions.
